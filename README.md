# kotlin-convenience-store-precourse

## 1. 초기 설정
- [ ] 상품 목록 저장하기
- [ ] 프로모션 목록 저장하기

## 2. 프로그램 시작
- [ ] 환영 인사 출력
- [ ] 재고 출력
- [ ] 주문 입력 받기
- [ ] 주문 형식 검증하기

## 3. 프로모션 계산
- [ ] 항목 별 프로모션 날짜 검증하기
- [ ] 남아있는 프로모션 재고 확인하기
- [ ] 주문 품목을 확인하고 증정해야 할 프로모션 제품 개수 확인하기 
- [ ] 증정 불가능할 경우 정가 결제 메시지 출력 후 진행 여부 입력받기
- [ ] 증정 가능할 경우
  - [ ] 수량을 추가해야 되는 경우 수량 추가 여부 입력 받기
- [ ] 프로모션 재고를 우선적으로 차감하기
- [ ] 증정 품목 정리하기
- [ ] 행사 할인 가격 정리하기

## 4. 멤버십
- [ ] 멤버십 여부 입력 받기
- [ ] 프로모션 미적용 금액에서 30% 멤버십 할인, 최대 한도 8,000원

## 5. 마무리
- [ ] 내야될 돈 계산하기
- [ ] 영수증 출력하기
- [ ] 종료할지, 또 구매할지 여부 입력 받기
